Clothing tags for the current character. Added to every image of her (except Me and Background), so she wears the same outfit every time. Be precise — slim black lace nightgown with thin straps pins better than dress. Stored per character avatar.
Your outfit: you
Clothing tags for your persona. Added to images that show you (Me, The Whole Story, The Last Message, free prompts), skipped for Yourself, Your Face and Background. Stored per persona.
How hard the appearance and outfit tags are pushed against the scene (1.2 = recommended, 1 = plain tags without emphasis). This is what keeps the outfit stable when the scene itself describes clothes. The outfit can still change a little between images while the seed is -1 (random).
Scene prompt source
When enabled (or when /swarm is used with no prompt), the chat model writes the scene description from the recent chat instead of using the raw message text.
If this instruction asks for clothing (wearing, outfit, dress…), the scene will describe clothes of its own and fight the outfit boxes. Telling the model to skip clothing keeps the outfit stable.
The caret next to "Generate Image (SwarmUI)" in the wand menu opens the same "Send me a picture of:" list as SillyTavern's built-in image extension: Yourself, Your Face, Me, The Whole Story, The Last Message, Raw Last Message and Background. The same shortcuts work as /swarm you, /swarm face, /swarm me, /swarm scene, /swarm last, /swarm raw_last and /swarm background.
Generation modes
The popup shows only the chat prompt (the part taken from the chat, or the prompt you typed after /swarm). The appearance/outfit tags, prefix/suffix tags, LoRA tags and the negative prompt are added automatically when you press Continue.
The wand menu entry, the message button and Generate now then ask first: New prompt (the chat model is asked when "Let the chat LLM write the scene prompt" is on — this uses tokens) or Old prompt, new image (reuses the chat prompt of the last image and costs nothing). Nothing is asked before the first image exists.
Interface
Generate from "Generate Image (SwarmUI)" in the wand menu next to the chat box, or from the blue wand button under any message - both use SwarmUI. SillyTavern's own paintbrush button is left exactly as it was.
